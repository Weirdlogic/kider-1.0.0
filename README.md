# The Leabridge School Website

Website for The Leabridge School (Ikeja) — a private creche, pre-school and primary school in Ikeja, Lagos, blending British, Montessori and Nigerian curricula.

## Structure

- `index.html`, `about.html`, `classes.html`, `facility.html`, `team.html`, `testimonial.html`, `appointment.html`, `call-to-action.html`, `contact.html`, `404.html` — site pages
- `assets/css` — stylesheets
- `assets/img` — photos and branding
- `assets/js` — scripts
- `assets/lib` — third-party front-end libraries (Bootstrap, Owl Carousel, WOW, etc.)
- `CNAME` — custom domain for GitHub Pages

## Deployment

This site is static and deploys directly via GitHub Pages from the repository root on the `main` branch.
